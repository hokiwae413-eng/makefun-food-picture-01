A Python program (standard library only) that draws one picture of food — a golden crispy fried-chicken plate with fries, glossy ketchup, a lemon wedge and rising steam on a red-white gingham liner — and writes it to entry.png as a hand-encoded PNG. Deterministic: every run produces byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
